# Ensure player_id column exists in an Opta data.table

Ensure player_id column exists in an Opta data.table

## Usage

``` r
.ensure_player_id(dt, fn_name = "spm_opta")
```

## Arguments

- dt:

  data.table with player data

- fn_name:

  Character function name for warning messages

## Value

dt (modified by reference)
