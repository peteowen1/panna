# Summarise what the adjacency table found

Reports the names it actually saw rather than the ones the constants
claim, so a reader can check the ids in `NG_ATTRIBUTION_TYPES` against
reality.

## Usage

``` r
.ng_report_adjacency(adj)
```

## Arguments

- adj:

  Output of
  [`ng_build_adjacency()`](https://peteowen1.github.io/panna/reference/ng_build_adjacency.md)
