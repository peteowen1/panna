# Map Host-Name Aliases to Canonical Opta team_name

Tournament season strings encode the host country (e.g., "2024 USA") but
the host may appear under a different spelling in opta_lineups (here
"United States"). This map normalises common aliases.

## Usage

``` r
ELO_HOST_NAME_ALIASES
```

## Format

An object of class `character` of length 6.
