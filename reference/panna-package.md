# panna: Player Rating System for Football Using RAPM, SPM, and EPV Methods

Implements player ratings for football (soccer) from 'Opta' event and
tracking-adjacent data. Combines Regularized Adjusted Plus-Minus
('RAPM') with Statistical Plus-Minus ('SPM') as a Bayesian prior,
analysing time segments with constant lineups ('splints') to estimate
each player's contribution to expected goals ('xG') differential.
Action-level Expected Possession Value ('EPV') and win probability added
('WPA') models support decay-weighted rating composites (EPR, PSR,
Panna, Piero) plus match prediction and tournament simulation.
