# Predict xGOT for prepared shot features

Predict xGOT for prepared shot features

## Usage

``` r
predict_xgot(xgot_model, shot_features)
```

## Arguments

- xgot_model:

  Fitted model from fit_xgot_model().

- shot_features:

  Data frame with the model's feature columns.

## Value

Numeric vector of xGOT predictions.
