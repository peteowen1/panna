# Is a player-season eligible for a PSR leaderboard? (panna#215)

Returns a logical vector, one per row — deliberately NOT a filtered
table. A low-minutes rating is still that player's best available
estimate; it is only too noisy to *rank* against a full season. Keep the
rows, flag them, and let the display decide.

## Usage

``` r
psr_leaderboard_eligible(psr_dt, min_90s = MIN_90S_PSR_LEADERBOARD)
```

## Arguments

- psr_dt:

  Table containing `weighted_90s`.

- min_90s:

  Minimum weighted 90s; defaults to
  [`MIN_90S_PSR_LEADERBOARD`](https://peteowen1.github.io/panna/reference/MIN_90S_PSR_LEADERBOARD.md).

## Value

Logical vector. `NA` or missing `weighted_90s` is treated as NOT
eligible — an unknown workload cannot clear a workload bar.

## Details

Without this, 23 of the outfield top 100 are sub-15-nineties
part-seasons (Totti 7.0, Pinilla 5.5, Pastore 9.7).
