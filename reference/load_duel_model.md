# Load the pre-trained xDuel model

Load the pre-trained xDuel model

## Usage

``` r
load_duel_model(path = NULL)
```

## Arguments

- path:

  Optional explicit path. Falls back to pannamodels, then local.

## Value

Fitted xDuel model.
