# Save the xDuel model

Save the xDuel model

## Usage

``` r
save_duel_model(duel_model, path = NULL)
```

## Arguments

- duel_model:

  Fitted model.

- path:

  Optional path. Defaults to pannadata opta/models/duel_model.rds.

## Value

Invisibly, the path.
