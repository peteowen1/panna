# Canonical defense predictor columns for the SKILL-based SPM

See
[`.skill_spm_offense_cols()`](https://peteowen1.github.io/panna/reference/dot-skill_spm_offense_cols.md)
for why this is a separate (smaller) set from the box-score SPM's
defense columns.

## Usage

``` r
.skill_spm_defense_cols(data)
```

## Arguments

- data:

  Data frame of candidate features

## Value

Character vector of defense predictor columns present in `data`
