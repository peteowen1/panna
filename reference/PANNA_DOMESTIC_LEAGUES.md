# Domestic-only competitions (for league-offset attribution)

The subset of `PANNA_RATING_LEAGUES` that is a domestic league. Used
when attributing a player-season to "the league he plays in", which must
be a domestic competition – a cross-league cup is where leagues MEET,
not a league a player belongs to.

## Usage

``` r
PANNA_DOMESTIC_LEAGUES
```

## Format

Character vector of domestic competition codes
