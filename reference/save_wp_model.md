# Save WP model

Save WP model

## Usage

``` r
save_wp_model(wp_model, path = NULL)
```

## Arguments

- wp_model:

  WP model from
  [`train_wp_model`](https://peteowen1.github.io/panna/reference/train_wp_model.md).

- path:

  Directory to save. If NULL, uses `pannadata/data/opta/models/`.

## Value

Invisibly returns the file path.
