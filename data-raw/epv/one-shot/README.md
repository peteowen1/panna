# One-shot publishers (archived)

Scripts here already ran once and published model assets that are LIVE now. Re-running one
overwrites those assets, so each stops unless `ALLOW_ONE_SHOT=1` is set. Kept for the record of
what was published and how to roll back (each writes a backup of the published files first).

- `pack_publish_v51.R`: xG v5.1 / xGOT v3.1 pack (2026-09-28).
- `pack_publish_v52.R`: xG v5.2 / xGOT v3.2 (panna#277, 2026-10-06), the live xG today.
