## Findings (reviewed 2026-04-21)

### ✅ Working as expected

- **SHOOTING**: Kane, Mbappé, Messi, Lewandowski, Salah, Immobile, Ronaldo, Suárez — textbook finisher list. Per-90 dominated by strikers (Jonas, Giakoumakis, Mbappé, Ibrahimović, Dost, Eto'o, Agüero, Bale). Matches archetype perfectly.
- **DEFENDING**: Van Dijk, Acerbi, Otamendi, Dani Parejo, Casemiro, Rodri-type centre-backs and holding mids dominate career totals. Correct.
- **OFFENSE (overall)**: Messi → Mbappé → Kane → Salah → Bruno Fernandes → Tadić → De Bruyne → Kimmich → Lewandowski. Matches domain intuition.
- **CROSS-COMPONENT imbalance**: Most attack-skewed are all pure strikers (Jonas, Giakoumakis, Messi, Mbappé, Dost, Eto'o, Ibrahimović); most defense-skewed are pure defenders. Confirms the O/D split picks up archetype rather than just volume.

### ⚠️ Issues discovered

1. **PASSING is dominated by goalkeepers.** Top 20 by career total: Messi (#1), then Pickford (#2), Baumann (#3), Muslera (#7), Salah (#8), Schmeichel (#10), Hrádecký (#12)… 14 of the top 20 are GKs. Cause: `aggregate_player_game_epv()` groups action types as:
   ```r
   epv_passing = c("pass", "ball_touch", "keeper_pick_up", "keeper_claim", "keeper_punch")
   ```
   So every keeper pick-up / claim / punch accumulates positive EPV credit under "passing". Keepers routinely handle the ball in low-EPV safe states, so the volume adds up.

   **Options**: rename to `epv_distribution`; or split keeper actions into a new `epv_keeping` component. The bug is in `panna/R/epv_model.R:1433`.

2. **DRIBBLING includes aerial duels.** Definition: `epv_dribbling = c("take_on", "aerial")`. Per-90 leaderboard mixes dribble-carriers (Doku, Neymar, Traoré, Rafa) with target strikers who win flick-ons (Peter Crouch, A. Nuhiu, B. Dost, R. Gestede, C. Benteke). Not strictly wrong — aerial duels are also 1v1 actions — but the label "dribbling" misleads.

   **Option**: rename to `epv_1v1` or split `epv_takeon` + `epv_aerial`.

3. **Per-90 leaderboards with >=2700 min (30 games) still pick up low-sample players** at the extremes — obscure single-season CBs (Douglão, Lescott, Anđelković, etc.) top the defending per-90 list. Consider raising the minutes cutoff or showing top by (z-score × log(minutes)) for more stable ranking.

### Summary

Core EPV decomposition works. The O/D split and overall offense/defense are solid. The two action-type bucketing issues (keepers in passing, aerials in dribbling) are labelling problems rather than model bugs — the credit assignment itself is fine, but the names we're exposing on the blog/leaderboards will mislead unless fixed.

## Resolution (2026-04-21)

Both mis-labelling issues were fixed in `panna/R/epv_model.R` by splitting the `action_types` map:

```r
# Before (single bucket each):
epv_passing   = c("pass", "ball_touch", "keeper_pick_up", "keeper_claim", "keeper_punch")
epv_dribbling = c("take_on", "aerial")

# After (split into distinct components):
epv_passing   = c("pass", "ball_touch")
epv_dribbling = "take_on"
epv_aerial    = "aerial"       # NEW
epv_keeping   = c("keeper_pick_up", "keeper_claim", "keeper_punch")  # NEW
```

`epv_offensive` total is preserved — it now sums `passing + shooting + dribbling + aerial + keeping + receiver`, which equals the previous definition because the split only relabels existing credits.

Verified via `panna/debug/smoke_test_epv_split.R`:
- `epv_keeping > 0` is populated only for goalkeepers (Ramsdale, Kepa in test match)
- `max |epv_offensive - sum(components)| < 1e-9` (invariant preserved exactly)

Re-run `10b_backfill_game_logs.R` to push corrected leaderboards to the blog-latest release.
